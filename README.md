# เหล่าซือไหม · เว็บฝึกพูดภาษาจีน

- `index.html` หน้านักเรียน: คำศัพท์อาหาร 8 คำ (ภาพ, ปุ่มฟัง/ฟังช้า, ปุ่มพูด + กราฟวรรณยุกต์ + คะแนน) และส่วน "ส่งการบ้าน"
- `admin.html` หน้าครู: รายชื่อนักเรียน, ดูวิดีโอ, ติ๊ก "ตรวจแล้ว", ลบ
- `apps-script/Code.gs` ระบบรับวิดีโอ (เก็บใน Google Drive + รายชื่อใน Google Sheet ของครู)

## ขั้นที่ 1: ตั้งค่า Google Apps Script (ทำครั้งเดียว)
1. ไปที่ https://script.google.com > โครงการใหม่ ตั้งชื่อ "เหล่าซือไหม"
2. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs`
3. **เปลี่ยนรหัสผ่านหน้าครู** ที่บรรทัด `const ADMIN_PASSWORD = 'laoshi1234';`
4. บันทึก > เลือกฟังก์ชัน `setup` > กด "เรียกใช้" > อนุญาตสิทธิ์ (Advanced > Go to … (unsafe) > Allow)
   ระบบจะสร้างโฟลเดอร์ "เหล่าซือไหม - การบ้านวิดีโอ" และชีตรายชื่อใน Drive ของครู
5. กด "ทำให้ใช้งานได้" (Deploy) > การทำให้ใช้งานได้รายการใหม่ > ประเภท "เว็บแอป"
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คัดลอก URL ที่ลงท้ายด้วย `/exec`

## ขั้นที่ 2: ใส่ URL
เปิด `config.js` แล้ววาง URL แทน `PASTE_YOUR_APPS_SCRIPT_URL_HERE`

## ขั้นที่ 3: ขึ้นเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่ เช่น `laoshi-mai` แล้วอัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ `img`)
2. Settings > Pages > Branch: `main` / root > Save
3. หน้านักเรียน: `https://<ชื่อผู้ใช้>.github.io/laoshi-mai/`
   หน้าครู: `https://<ชื่อผู้ใช้>.github.io/laoshi-mai/admin.html`

## หมายเหตุ
- ปุ่มพูดต้องเปิดผ่าน https (GitHub Pages ใช้ได้) และอนุญาตไมโครโฟน ใช้ได้ดีที่สุดบน Google Chrome (Android/คอม)
- กราฟวัดระดับเสียงสูง-ต่ำจากไมโครโฟนจริง แล้วเทียบกับรูปวรรณยุกต์ที่ถูกต้อง (เส้นประ) ถ้าเบราว์เซอร์รองรับการรู้จำเสียงพูด จะตรวจว่าพูดคำถูกด้วย
- วิดีโอสูงสุด 300 MB ต่อไฟล์ หลังส่ง Drive อาจใช้เวลาประมวลผลวิดีโอสักครู่ก่อนเล่นได้ในหน้าครู
- ถ้าแก้ไข Code.gs ภายหลัง ต้อง Deploy > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่ (URL เดิม)
- เพิ่ม/แก้คำศัพท์: แก้รายการ `WORDS` ใน `index.html` และใส่รูปในโฟลเดอร์ `img`
